# 前端开发说明（Vue 3 + TypeScript + Vite）

该前端项目基于 Vue 3 + TypeScript + Vite。日常开发采用 `<script setup>` 语法，建议先阅读 [script setup 文档](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup)。

如果你在搭建本地开发环境或配置 IDE，推荐参考 [Vue 官方 TypeScript 指南](https://vuejs.org/guide/typescript/overview.html#project-setup)。
